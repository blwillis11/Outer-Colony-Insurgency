# Outer Colony Insurgency

This mod works to create fictional innsurectionist forces, independent groups, and some UNSC groups stuck in a cycle of conflict.

This is a retexture mod utilizing mostly The Cole Protocol, with a few items from other mods such as Sci-fi Vehicles and Operation Trebuchet. If the required mod is not loaded, the mod will not load that Addon. Shouldn't cause any issues.

Gear randomization code by Crisco.
